# [M5] 화면 틀과 표본 넣기

## 목적
`tools/m5_notice_match.html` 하나로 PRD 4절의 화면 3개 틀을 만들고, 민원대장 CSV와 공고 이력 CSV를 파일 선택으로 읽어 화면에 보여 준다. 매칭(Issue 2)이 올라설 바탕을 만든다.

## 완료 기준
- [ ] HTML 파일 하나에 스타일·스크립트가 모두 들어 있다. 외부 주소·외부 라이브러리·fetch가 없다.
- [ ] 화면 3개(파일 올리기 / 매칭 결과 / 저장·백업)의 제목과 자리가 있다. 매칭 결과와 저장·백업은 빈 자리여도 된다.
- [ ] 파일 올리기 화면 맨 위에 "가상 표본만 넣으세요. 실제 민원 자료를 올리지 마세요" 안내가 보인다.
- [ ] 민원대장 CSV와 공고 이력 CSV를 각각 파일 선택으로 넣으면, 읽은 행 수와 처음 몇 행이 표로 보인다.
- [ ] 관련 S 번호: 없음. S1~S3을 넣을 입력 준비 단계다.

사람이 화면에서 볼 것
1. 파일을 더블클릭해 열면 맨 위에 실제 자료 금지 안내가 보인다.
2. `data/m5_sample.csv`를 민원대장으로, `data/m5/m5_notice_history.csv`를 공고 이력으로 넣으면 각 파일의 행 수와 미리보기 표가 보인다.
