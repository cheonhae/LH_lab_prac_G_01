# [M5] MVP 판정 — 접수일 기준 자동 매칭

## 목적
PRD 3절 매칭 규칙대로 민원마다 접수일에 유효했던 공고를 골라 매칭 결과 화면에 보여 준다. 도구는 확정하지 않는다.

## 완료 기준
- [ ] [매칭] 버튼을 누르면 민원마다 접수번호·접수일·사업명·적용 공고·근거·상태가 표 한 줄씩 보인다.
- [ ] 결과 표 위에 건수 요약(매칭 n건 / 확인 필요 n건)이 보인다.
- [ ] 같은 사업의 공고 중 게시일이 접수일보다 앞선 버전에서 가장 늦은 것을 고른다.
- [ ] 다음 네 경우는 적용 공고 칸을 비우고 "확인 필요: 사유"로 표시한다. 사업 없음 / 접수일 전 공고 없음 / 같은 날 게시 / 날짜 형식 오류
- [ ] 매칭된 건의 상태는 모두 "담당 검토 후 확정"이다.
- [ ] S1 (PRD 5절): 접수일 2026-11-15, 가상지구 A1 → 적용 공고 "정정 2차", 근거 "정정 2차, 2026-11-13 게시", 상태 "담당 검토 후 확정"
- [ ] S2 (PRD 5절): 접수일 2026-10-10, 가상지구 A1 → 적용 공고 "본공고", 근거 "접수일 당시 유효 — 정정 1차는 2026-10-20 게시"
- [ ] S3 (PRD 5절): 가상지구 Z9 → 적용 공고 칸 빔, 상태 "확인 필요: 공고 이력에 해당 사업 없음"

사람이 화면에서 볼 것
1. 표본을 넣고 [매칭]을 누르면 VM-2026-001, 002, 006 줄이 S1, S2, S3대로 보인다.
2. VM-2026-014(사업명 `가상지구 A 1`)가 A1으로 매칭되지 않고 "확인 필요"로 남는다.
