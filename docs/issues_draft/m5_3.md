# [M5] 저장·오류 안내·다듬기

## 목적
마지막 결과를 브라우저에 남기고 JSON으로 백업·복원한다. 잘못된 파일을 넣었을 때 무엇이 틀렸는지 화면에서 알 수 있게 한다.

## 완료 기준
- [ ] 저장은 localStorage 키 `m5_notice_match` 하나만 쓴다. 공고 이력과 마지막 매칭 결과가 들어 있다.
- [ ] 페이지를 다시 열면 마지막 결과가 다시 보인다.
- [ ] [JSON 내보내기]로 파일을 받고, [JSON 가져오기]로 되살리면 같은 결과 표가 보인다.
- [ ] 오류 안내
  - 파일을 하나만 넣고 [매칭]을 누르면 "민원대장과 공고 이력 파일을 모두 넣어 주세요" 안내가 보인다.
  - 열 이름이 PRD 4절과 다르면 어느 열이 없는지 보인다.
  - 빈 파일이면 "행이 없습니다" 안내가 보인다.
- [ ] 다듬기: 확인 필요 줄이 눈에 띄게(색 또는 표시) 구분된다.
- [ ] 관련 S 번호: S1~S3 결과가 저장 → 새로 고침 → 다시 보이기 후에도 같다.

사람이 화면에서 볼 것
1. 매칭 후 새로 고침해도 결과 표가 그대로 남아 있다.
2. 개발자 도구 Application 탭에 `m5_notice_match` 키 하나만 있다.
3. 열 이름을 바꾼 CSV를 넣으면 빠진 열 이름이 안내된다.

## 범위 밖
- 결과 CSV 내려받기, 붙여 넣기 입력 (PRD 7절 '다음')
- 같은 날 게시 공고의 업무 기준 반영 (PRD 7절 '추후')
