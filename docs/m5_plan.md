## 2. 성공 시나리오 (PRD 5절 그대로)

공고 이력 표본: 가상지구 A1 — 본공고 2026-10-01 / 정정 1차 2026-10-20 / 정정 2차 2026-11-13

- **S1 정정 반영**: 접수일 2026-11-15인 가상지구 A1 민원을 넣으면 → 적용 공고 "정정 2차", 근거 "정정 2차, 2026-11-13 게시", 상태 "담당 검토 후 확정"이 보인다.
- **S2 접수일 기준**: 접수일 2026-10-10인 가상지구 A1 민원을 넣으면 → 최신인 정정 2차가 아니라 적용 공고 "본공고", 근거 "접수일 당시 유효 — 정정 1차는 2026-10-20 게시"가 보인다.
- **S3 확인 필요**: 공고 이력에 없는 사업명(가상지구 Z9)이 적힌 민원을 넣으면 → 적용 공고 칸은 비고, 상태 "확인 필요: 공고 이력에 해당 사업 없음"이 보인다.

## 3. 표본 데이터

- 파일
  - 민원대장: `data/m5_sample.csv` (CSV, 가상, 15행, 열 `접수번호,접수일,사업명,민원요지`)
  - 공고 이력: `data/m5/m5_notice_history.csv` (CSV, 가상, 7행, 열 `사업명,공고구분,게시일`)
  - 행 번호는 머리행을 뺀 데이터 행 번호다 (1행 = VM-2026-001).
- 일부러 넣은 함정: 14행 — 사업명 표기 다름 (`가상지구 A 1`, 띄어쓰기). 짐작으로 A1에 맞추면 안 된다.
- 경계값
  - 4행 — 접수일 2026-11-13이 A1 정정 2차 게시일과 같은 날
  - 11행 — 접수일 2026-11-10이 C3 정정 1차 게시일과 같은 날
  - 5행 — 접수일 2026-09-28, A1 본공고(10-01) 전 접수
  - 10행 — 접수일 2026-11-01, C3 본공고(11-02) 하루 전 접수
  - 15행 — 접수일 2026-10-16, B2 변경 1차(10-15) 다음 날 접수
  - 13행 — 접수일 `2026/11/16`, 날짜 형식이 `YYYY-MM-DD`가 아님
- 기대값(도구를 돌리기 전에 사람이 표본을 열어 직접 셈 — 세션은 이 칸을 비워 두고, 사람이 불러 준 값만 적음):
  - S1: 1행(VM-2026-001, 접수일 2026-11-15, 가상지구 A1)의 적용 공고가 '정정 2차', 근거가 '정정 2차, 2026-11-13 게시', 상태가 '담당 검토 후 확정'으로 보인다.
  - S2: 2행(VM-2026-002, 접수일 2026-10-10, 가상지구 A1)의 적용 공고가 '정정 2차'가 아니라 '본공고'로 보인다.
  - S3: 6행(VM-2026-006, 가상지구 Z9)의 적용 공고 칸이 비고, 상태가 '확인 필요: 공고 이력에 해당 사업 없음'으로 보인다.
  - 건수: 15건 중 매칭 __건 / 확인 필요 __건 (확인 필요 행: __, __, __ …)
  - 함정: 14행(가상지구 A 1)은 A1으로 매칭되지 않고 '확인 필요'로 보인다.

## 4. 요구사항과 완료 기준

| ID | 요구사항 | 성공 (이 입력이면 이 결과) | 실패할 때 동작 | 경계 조건 |
|---|---|---|---|---|
| R1 | 민원대장·공고 이력 CSV를 파일 선택으로 읽어 행 수와 미리보기를 보여 준다 | 표본 두 파일 → 파일별 행 수와 미리보기 표 | 파일 하나만 선택 → 두 파일을 모두 넣으라는 안내 | 빈 파일, 열 이름이 PRD 4절과 다른 파일 |
| R2 | 접수일 기준으로 적용 공고를 고르고 근거·상태를 보여 준다 (MVP) | S1·S2·S3 (2절) | 규칙의 네 경우 → 칸 비움 + "확인 필요: 사유" | 접수일 = 게시일, 본공고 전 접수, 사업명 띄어쓰기 다름 |
| R3 | 결과를 키 `m5_notice_match` 하나에 저장하고 JSON으로 내보내기·가져오기 | 새로 고침·가져오기 뒤 같은 결과 표 | 형식이 다른 JSON → 가져오기 거부 안내 | 저장된 값이 없을 때 첫 실행 |

## 5. 작업

| 작업 | 목적 | 포함 / 제외 | 선행 | 검증 방법 | 크기 |
|---|---|---|---|---|---|
| T1 | 화면 3개 틀과 CSV 읽기 | 포함: 안내 문구, 파일 선택 2개, 미리보기 / 제외: 매칭, 저장 | — | 표본 두 파일을 넣고 행 수 확인 | S |
| T2 | 접수일 기준 매칭과 결과 표 | 포함: 매칭 규칙, 근거, 상태, 건수 요약 / 제외: 상세 근거, 사유별 분류, CSV 내려받기 | T1 | 2절 S1~S3, 3절 경계값·함정 행 확인 | S·M |
| T3 | 저장·백업·오류 안내 | 포함: localStorage 키 1개, JSON 내보내기·가져오기, 입력 오류 안내 / 제외: 붙여 넣기 입력 | T2 | 새로 고침 후 결과 유지, 백업 되살리기 | M |
