## CSV 열 설명 — `G-M2-01_민원대장_week1.csv` (UTF-8 BOM)

| 열 | 설명 |
|---|---|
| 접수번호 | `G1-001` 형식. 민원 1건에 번호 1개 |
| 접수일 | `YYYY-MM-DD` |
| 신청방법 | 민원이 들어온 경로: 콜센터, 온라인, 방문 |
| 민원유형 | 자격·소득, 접수 기간·방법, 제출 서류, 임대 조건, 기타 |
| 적용공고 | 민원이 기준으로 삼은 공고: `v1` = 최초 모집공고(2026. 10. 5.(월) 게시), `v2` = 정정공고 |
| 처리상태 | 접수, 처리중, 답변완료 |

## CSV 열 설명 — `G-M2-02_홍보예산_집행현황.csv` (UTF-8 BOM)

| 열 | 설명 |
|---|---|
| 항목코드 | `P-01` 형식 |
| 항목명 | 홍보 집행 항목 |
| 예산 | 배정 예산(쉼표 없는 정수) |
| 집행 | 집행액(쉼표 없는 정수) |
| 잔액 | 입력자가 적은 잔액 |

| 최종집행일 | `YYYY-MM-DD` |
