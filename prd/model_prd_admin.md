# PRD — 홍보 예산 집행 검증기

| 항목 | 내용 |
|---|---|
| 직군·부서 | 행정 · 가상주택공사 누리주거복지본부 주거복지부 임대공급팀 |
| 결과물 형태 | 업무 자동화 도구 — `scripts/budget_validator.py` + CLAUDE.md 규칙 |
| 입력 데이터 | `inputs/m2/G-M2-02_홍보예산_집행현황.csv` |
| 작성 | 2026. 11. 12.(목) · 실습용 예시 PRD |

## 1. 프로젝트 개요

- 해결하려는 문제: 홍보 예산 집행현황 파일에 단위 섞임·합계 행·비표준 입력이 섞여 있어 그대로 더하면 집행률이 틀린다.
- 배경: 여러 사람이 입력한 파일을 예산담당이 매주 집행률로 보고한다. 보고 때마다 이상한 행을 눈으로 찾는다.
- 기대 변화: 규칙으로 문제 행을 표시하고, 원본은 그대로 둔 채 정상 기준 집행률과 제외·수정 근거 파일을 만든다.

## 2. 사용자 분석

- 주 사용자: 임대공급팀 홍보 예산 정리 담당자, 주거복지부 예산담당.
- 사용 맥락: 주간 보고 전에 집행현황 파일을 검사하고, 무엇을 왜 빼거나 고쳤는지 근거와 함께 넘길 때.
- 현재 방식과 한계: 엑셀 합계 수식으로 더한다. 단위가 다른 행이나 합계 행이 그대로 더해지는 실수를 알아채기 어렵다.

## 3. 기능 요구사항

- 핵심 기능(우선순위 순)
  1. 규칙 검사 — `rules/aggregation_rules.md`에 적은 처리 기준(중복·단위 섞임·합계 행·비표준 표기 등)으로 행을 검사하고 규칙별 행 수를 센다.
  2. 정상 기준 집계 — 원 단위 예산·집행·잔액 합계와 집행률을 계산한다. 담당 확인이 필요한 행은 분리해 참고값만 따로 낸다.
  3. 근거 파일 — `summary.csv`, `excluded_rows.csv`(원본행·사유·원본값), `run_log.md`(수정 행 목록)를 만든다.
- 차별점: 문제 행을 지우지 않고 표시만 해서, 원본을 보존한 채 "무엇을 왜 뺐는지"를 파일로 남긴다.

## 4. 비기능 요구사항

- 사용 환경: Claude Code 클라우드 세션, Python 표준 라이브러리만 사용한다.
- 데이터 민감도: 가상 자료만 쓴다. 데이터를 외부로 보내지 않는다.
- 제약: 원본 CSV를 고치지 않는다. 비율은 최종 표시 단계에서 한 번만 소수 1자리로 반올림한다(0.5 올림).

## 5. 성공 지표

- 성공 모습: 담당자가 명령 한 줄로 검사하고, 만들어진 세 파일을 그대로 예산담당에 넘긴다.
- 핵심 지표: 8절 수용 기준 전 항목 통과.

## 6. 사용자 여정

1. 담당자가 세션에서 "budget_validator로 이번 주 집행현황을 검사해 줘"라고 지시한다.
2. 도구가 규칙별 행 수와 정상 기준 집행률을 출력한다.
3. 담당자가 `excluded_rows.csv`와 `run_log.md`에서 제외·수정 행을 원본과 대조한다.
4. 담당자가 정상 기준 집행률과 참고 집행률을 구분해 보고서에 적는다.

## 7. 단계별 개발 우선순위

- MVP: 4개 규칙 검사 + 규칙별 행 수 + 정상 기준 집계
- 다음: 근거 파일 3종, 담당 확인 행 참고값
- 추후: 다른 주차 자료 형식 점검, 주별 집행 추이

## 8. 수용 기준

| # | 기준 | 확인 방법 | 결과 |
|---|---|---|---|
| AC1 | 제외·수정한 행마다 사유가 `excluded_rows.csv` 또는 `run_log.md`에 있다 | 두 파일의 행을 원본 CSV 행 번호와 대조 | ☐ 통과 ☐ 수정 |
| AC2 | 집계 포함 행 수가 `outputs/m2/check.md`의 두 번째 방법 값과 같다 | `summary.csv`의 '집계 포함 행 수'와 check.md 대조 | ☐ 통과 ☐ 수정 |
| AC3 | 예산 합계·집행 합계가 `outputs/m2/check.md`의 두 번째 방법 값과 같다 | `summary.csv`와 check.md 대조 | ☐ 통과 ☐ 수정 |
| AC4 | 집행률이 두 번째 방법 값과 같고 최종 표시 단계에서 한 번만 반올림했다 | `summary.csv`의 '집행률'과 check.md 대조, 스크립트의 반올림 위치 확인 | ☐ 통과 ☐ 수정 |
| AC5 | 담당 확인이 필요한 행의 참고값이 정상 기준 집행률과 구분된 행으로 나온다 | `summary.csv` 확인 | ☐ 통과 ☐ 수정 |
| AC6 | 원본 CSV가 바뀌지 않았다 | 세션 diff에서 `inputs/` 아래 변경 0건 확인 | ☐ 통과 ☐ 수정 |

## 9. 위험 요소

- 단위를 보지 않고 더하면 일부 행이 다른 크기로 들어가 집행률이 틀린다.
- 합계 행을 데이터로 더하면 합계가 크게 부풀어 오른다.
- 문제 행을 지우면 근거가 사라진다 — 지우지 않고 분리 표시한다.

## 10. 판단 경계

- 이 도구는 예산 집행의 적정성·계약금액을 확정하지 않는다. 정정 행 반영 여부와 결과는 담당자가 확인한다.
