# 집계 기준 — 민원대장·홍보 예산 집행현황

> 원본 CSV(`inputs/`)는 고치지 않는다. 이 기준대로 `scripts/aggregate.py`가 계산한다. 제외한 행은 `outputs/{모듈}/excluded_rows.csv`에 사유와 함께, 고쳐서 포함한 행은 `run_log.md`의 수정 행에 남긴다.

## 1. 공통

- 행 번호는 머리행을 뺀 데이터 행 번호(1부터)로 쓴다. 표기 예: `G-M2-01 12행`.
- 비율은 최종 표시 단계에서 한 번만 소수 1자리로 반올림한다(0.5 올림, 중간 합계는 반올림하지 않음).

## 2. 민원대장

### 2.1 중복

- 접수번호가 같은 행은 같은 민원이다. 처음 나온 행만 세고, 두 번째 이후 행은 "중복"으로 제외한다.

### 2.2 집계 항목

- 민원유형별 건수: 자격·소득 / 접수 기간·방법 / 제출 서류 / 임대 조건 / 기타
- 신청방법별 건수: 콜센터 / 온라인 / 방문
- 처리상태별 건수와 미처리 건수(미처리 = `접수` + `처리중`)

## 3. 홍보 예산 집행현황

검사 순서: 합계 행 → 단위 → 음수 정정 → 잔액.

| 순서 | 규칙 | 처리 |
|---|---|---|
| 1 | 첫 열이 `합계`인 행 | 제외("합계 행") — 데이터로 더하지 않음 |
| 2 | `단위`가 `천원`인 행 | 예산·집행·잔액 ×1,000으로 원 환산 후 포함(수정 행 기록) |
| 3 | `집행`이 음수인 행 | "정정 — 담당 확인"으로 분리, 정상 집계에서 제외. 정정 반영 참고값만 따로 계산 |
| 4 | `잔액` ≠ `예산` − `집행` | 잔액을 예산 − 집행으로 다시 계산해 포함(수정 행 기록) |

- 집행률 = 집행 합계 ÷ 예산 합계 × 100(집계 포함 행 기준).
- 정정 반영 참고 집행률 = (집행 합계 + 정정 행 집행) ÷ (예산 합계 + 정정 행 예산) × 100. 보고서에는 정상 기준 집행률과 구분해 "참고"로만 쓴다.
- 이 기준은 집행의 적정성을 판단하지 않는다. 정정 행 반영 여부는 예산담당이 확인한다.
